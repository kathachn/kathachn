## Selected Project

### [QuantRiskLab](https://github.com/kathachn/QuantRiskLab)

A quantitative portfolio risk analytics engine developed as my Harvard CS50x Final Project.

- Historical, Gaussian, and Monte Carlo Value at Risk (VaR) and Expected Shortfall
- Multi-asset portfolio analytics and configurable stress testing
- Rolling out-of-sample VaR backtesting and Kupiec coverage testing
- Interactive Flask dashboard and quantitative visualisations
- Modular Python architecture validated with 82 automated tests

**Technologies:** Python · NumPy · pandas · SciPy · Flask · pytest
